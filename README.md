# 🎁 Birthday Surprise 2.0

A mobile-first birthday surprise website built with HTML, CSS and vanilla JavaScript. Create a shareable link, set a 4-digit pass key, and let your favourite person unlock a birthday experience. 💗

## Features
- Create your own surprise link with names and gender selections.
- Set a personal 4-digit pass key.
- Copy and delete up to 3 links saved in the current browser.
- Personalised birthday letter using the favourite person's name.
- YES/NO interaction, memories gallery, interactive cake and animated letter.
- Welcome popup with Create your own and Feedback options.
- Responsive mobile-first layout.

## Live website
https://mainakgarai007.github.io/Birthday-surprise-2.0/

## How to use
1. Open the live website and choose Create your own.
2. Select the genders and enter your name and your favourite person's name.
3. Set a 4-digit pass key and create the link.
4. Copy the link and send it to your favourite person.
5. They open the link, enter the pass key, and unlock the surprise.

## Notes
- Links are saved in this browser only; they are not synced between devices.
- The pass key is included in encoded link data. Do not use this for confidential information.
- Cross-device link-open analytics needs a backend and is not enabled yet.
